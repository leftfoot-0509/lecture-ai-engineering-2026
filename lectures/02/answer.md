### LLMによりデータを作成した際に用いたプロンプト
#### `GROUNDED`をデータ拡張するためのプロンプト（gemini3.5 Flash-Lite）
```
「教材の公開はいつですか」を4パターンで言い換えてください。なお、出力形式は「""」で括り、各文章の間には「,」と半角スペースを入れてください。
```
※ 「教材の公開はいつですか」は適宜変更した。


#### `UNGROUNDED`作成プロンプト（gemini3.5 Flash-Lite）
```
以下のFAQに情報が含まれていない、質問を10問作成してください。

GROUNDED = {・・・}  # 全文入力した
```

#### テスト用`GROUNDED`作成プロンプト（Claude Sonnet 5.5）
```
["教材の公開はいつですか", "教材の公開日はいつですか", "教材はいつ公開されますか", "いつから教材を見ることができますか", "教材の閲覧開始はいつですか" *]と同様の質問を作成してください。なお、なお、出力形式は「""」で括り、各文章の間には「,」と半角スペースを入れてください。また、2パターンは異なるトーンとなるようにしてください。
```
